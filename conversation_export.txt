drafter is a specific python module, can you research into it right now?

CLAUDE
Drafter is a student-friendly web development library for Python. It lets you build interactive websites out of plain Python functions and dataclasses, without needing HTML, JavaScript, or a framework like Flask.

How it works (v2):
- You write a script that ends with start_server(...). Quick start: pip install drafter, then "from drafter import *" and start_server(State("Welcome to my site.")).
- Run with: python my_site.py, drafter my_site.py, or python -m drafter my_site.py.
- Python runs normally on your machine and starts a local Starlette/uvicorn dev server. The served page boots a Python-in-the-browser engine (Pyodide by default, or Skulpt) and re-runs your code there.
- "drafter my_site.py --compile" produces a fully static site you can host on GitHub Pages, Netlify, etc.

Options: --theme (default, dark, none), flags for engine, page title, port/host, auto-reload; matching DRAFTER_* environment variables; JSON config files.

Project details: MIT license, Python 3.10+, docs at drafter-edu.github.io/drafter, source at github.com/drafter-edu/drafter. The 1.x line runs through at least 1.9.x; the current docs describe the v2 rewrite (2.0.x / 2.1.x on PyPI). v1 and v2 APIs may differ, and many tutorials probably cover v1.

Sources:
- https://pypi.org/project/drafter/2.1.3/
- https://pypi.org/project/drafter/2.0.2/
- https://pypi.org/project/drafter
- https://pypi.org/project/drafter/1.9.1/
- https://github.com/drafter-edu/drafter

I get this error, how do I put parameters in route buttons?

CLAUDE
You pass parameters to a route button with an Argument, as the third item in Button (from the Drafter student docs):

  Button("Submit", some_route, Argument("additional_info", "extra_data"))

Argument(name, value): the name must exactly match the route function's parameter name; the value can be a string, int, float, or bool.

Option 1 - pass the argument:
  Button("View Base Stats", "baseStatsPage", Argument("characterName", character.name))
(then characterOverviewPage must be a @route taking characterName: str, since an Argument can't carry a Character object)

Option 2 - store the name in state, so no button needs arguments (recommended for this project). If you use this, remove the characterName parameter from baseStatsPage.

Your original code passed the argument as a bare value, Button("Back to Overview", "overview", characterName); it must be wrapped in Argument("characterName", characterName).

Source: https://drafter-edu.github.io/drafter/students/docs.html

  @route
  def search(state: State, query: str) -> Page:
      state.query = query
      cleanedInput = cleanUpSearch(query)

      if not cleanedInput:
          state.results = []
          state.message = "Please enter a search."

      elif isName(cleanedInput):
          character = directSearch(cleanedInput)
          state.currentCharacter = character.name
          return characterOverviewPage(state)

      else:
          filteredCharacters = filterCharacters2(cleanedInput)
          state.results = [character.name for character in filteredCharacters]
          if state.results:
              state.message = "Matching characters:"
          else:
              state.message = "No matching characters found."

      return index(state)

Usual causes: state was overwritten by a line like "state = ..."; the wrong word before the dot (e.g. character.name.currentCharacter); parameters in a different order/names (Drafter expects the first parameter to be state); State doesn't match the start_server(State(...)) values.
